# Azure Carousel Generator

A beautiful tool for creating professional LinkedIn carousels with an Azure-inspired design. Built with Vue.js and Vite.

## Features

- Create beautiful LinkedIn carousel slides with a clean, modern Azure-inspired design
- Highlight key terms with a mint green background using `=highlighted text=` syntax
- Automatic formatting with proper spacing and typography
- Custom light blue gradient background with subtle grid pattern
- Export directly to PDF for easy sharing
- Automatic generation of title and ending slides

## Getting Started

### Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production

```bash
# Build for production
npm run build

# Preview production build
npm run serve
```

## GitHub Pages Deployment

This project is configured to automatically deploy to GitHub Pages using GitHub Actions.

1. Push your changes to the main branch
2. GitHub Actions will automatically build and deploy to GitHub Pages
3. View your live site at: https://[your-username].github.io/devopsCarousel/
